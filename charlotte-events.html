Music Bingo & Trivia in Charlotte, NC

Fat City Entertainment spent years hosting live trivia, music bingo and game shows around Charlotte — brewery nights in NoDa, drag queen game shows, and a run of weekly events across the city. Those shows are where a lot of what we sell was tested. Today the fastest way to run a music bingo or trivia night in Charlotte is to host it yourself, using the same games we ran there.

Run your own Charlotte night

Every game is a download, so it works the same in Charlotte as anywhere else — no travel fee, no date to book, nothing to wait for. Each music bingo pack prints up to 250 randomized cards and comes with a callsheet and a ready-made Spotify and Apple Music playlist, so you are not building a set list the night before.
