# Holiday 2026 sends: Halloween last call to New Year's

**Written 9 Oct 2026.** Seven sends, Sender, the ~2,000 list. Every one is short
on purpose (the owner's steer: lead with what it is, a few lines, one button).
Paste-ready. **Customer-facing, so no em-dashes**, and none are used below.

**The rule for every send:** one link, used on the header image, the body link
and the button, so GA4 counts one session per click. Prices below were read off
the product pages on 9 Oct 2026; re-read them if anything is repriced first.

**Every discount below is a dated LemonSqueezy code** (see `HOLIDAY-SALE-2026.md`
for the dashboard settings) and is applied at checkout automatically by
`ls-buy.js` from any product page or `/go/` page **once its entry is `live`**.
So the email can say "no code needed". Do not send a sale email until the
agent has confirmed that sale's entry is live; a send that promises a discount
the checkout does not apply is the worst thing these can do.

`_content/email-sends/halloween-2026.md` is still the main Halloween send. If it
has not gone out, send it **this weekend** with the one-line addition marked
below, then send #1 here as the last call. If it has, skip straight to #1.
