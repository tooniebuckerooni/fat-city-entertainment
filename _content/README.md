# `_content/` — source material, not part of the site

Working copies of content that hasn't shipped yet. Nothing here is linked from
the site and `robots.txt` disallows `/_content/`, the same as `/_tools/`.

**These files are still publicly fetchable.** GitHub Pages serves every file in
the repo, and a `robots.txt` disallow only asks well-behaved crawlers not to
index them — it does not restrict access. Anyone who guesses the path can read
them. So: draft copy and content plans are fine here; credentials, customer
data, and anything genuinely private are not.
